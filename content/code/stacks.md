**This site:** Go, [templ](https://templ.guide/), Tailwind v4, compiled to static HTML and
served from Cloudflare Pages. No Node in the project at all. No runtime, so nothing to
operate and nothing to pay for.

**Why not Next.js.** Because the interesting part of this site is the typography and the
motion, and neither of those gets easier with a framework. What a framework would have
added is a build I do not control and a dependency tree I would be patching in a year.
